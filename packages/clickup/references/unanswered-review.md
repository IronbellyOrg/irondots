# Unanswered review
Load only for a scoped message review. Inputs: verified user identity, permitted channels/people, lookback/cutoff, finite channel/page/message budgets and existing evidence. Output: source-linked candidate queue with coverage and uncertainty. Permitted effects: authorized bounded reads and local drafting only.

Delegate scoped discovery and synthesis to Brain using unchanged authoring-delegation/v1 and separately verified destination. Native reads are limited to audience/transport checks and targeted independent verification, not a parallel inbox sweep. Capture pagination cursors/has_more, query scope, exact channel/message/thread IDs and times. Stop at declared scope, preserving partial coverage rather than silently widening. Read thread context/replies when needed within budget. has_replies=false, unread state or reactions do not prove unanswered. Classify direct question, action request, FYI, resolved elsewhere, ambiguous or unknown. Include evidence and why action is proposed; let the user mark handled elsewhere or defer without task creation.

Resolve actual recipients/membership with the recipient-resolution skill; channel creator and display name are insufficient. Unknown recipient or group visibility blocks send readiness, not review. Draft exact replies locally while discussing, without a call per edit. Do not infer future authorization from a request to review. Return candidate IDs, source links, cutoff, fetch/source timestamps, coverage gaps and local proposals to batch-plan; never send from this module.
