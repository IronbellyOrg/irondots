# Evidence and selection

Load before judging. Inputs: issue ledger, actual source evidence, frozen criteria and advocate outputs. Output: eligibility, tradeoffs, supported recommendation or no selection. Semantic judgments remain judgments.

For every applicable criterion, record claim, exact evidence/location, verdict and rationale. Verdicts: met, not_met, unknown, not_applicable. Explain unknown and not-applicable. A source quote proves what a source says, not that its assertion is true. Requirement-ID mentions, numbers and heading counts are diagnostics, not semantic coverage or correctness. Preserve minority counterevidence and gaps; repeated assertions are one evidence family.

Apply critical eligibility gates first. A critical not_met or unknown prevents an unconditional recommendation for that candidate. If all candidates fail, recommend repair, evidence gathering or no eligible base; do not suspend the gate because all failed. Accepted risk is a separate user decision, not a factual fix or permission override. Assess criticality proportionately to the user's decision; do not invent risk to force ceremony.

Then compare eligible choices against the user's priorities and documented tradeoffs. A tie can remain a tie. Normal/deep runs re-evaluate finalists in reverse presentation order; resolve changed judgments by evidence. Record quick-mode omission of this check. This is a bias check, not proof that bias has been eliminated.

When `mask_authorship` is requested, create evaluation copies with author/model attribution metadata hidden and stable neutral variant IDs. Preserve originals and a private mapping. Do not replace substantive technical model/product names, source quotations, evidence or claims. Masking does not make identical evidence independent.

Use weighted scores only when requested. Freeze stable criterion IDs, applicability, weights and normalization before evaluation. Expose met, failed and unknown criteria separately; never remove unknown criteria to inflate a normalized score. Derive denominators from the actual applicable registry, exclude not-applicable criteria with reasons, and return null if no denominator exists. Verify arithmetic and critical eligibility independently of totals. Never label advocate unanimity as a confidence percentage. No accuracy, speed or cost benefit is claimed without applicable measurement.

For missing evidence, continue supplied-evidence analysis. Additional research must be within actual authorization, source/privacy bounds and finite effort. Discover/read the registered adaptive-research skill before using its current request/result contract. If unavailable, name the gap rather than silently substituting a research workflow. Domain validation beyond the evidence inspected remains the caller's acceptance responsibility.
