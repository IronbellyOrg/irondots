# Conditional deep methods and delegation

**Module contract:** Load for deep mode or explicitly warranted bounded challenge/delegation. Input: finite plan, evidence and critical gaps. Output: challenged findings and updated coverage within the same authority/effort envelope. Optional workers are not required for serial research; explicitly required independent review is required.

Identify competing explanations, decision-reversing assumptions and the strongest material contrary evidence. Examine methods, versions, applicability and source families. Trace bounded conceptual/entity/time/causal chains only for named gaps, keeping visited nodes. Do not infer causation from chronology or expand endlessly because certainty is unavailable. The finite single-pass fallback still applies without configured ceilings.

Delegate only independent bounded questions when useful and available; serial execution remains valid. Each worker receives request ID, objective/question, allowed/excluded scope and sources, privacy boundaries, effort allocation, actual resource locations, result contract, stopping conditions and output owner. Review/test workers should not receive expected answers that contaminate independent evaluation.
Workers return actual source/claim/coverage records, gaps and observable effort. Coordinator checks consequential evidence, deduplicates families, reconciles conflicts and is the single final writer. Worker assertions are not proof of actual tool execution; prompt boundaries are not runtime isolation guarantees.
Missing required reviewer/source blocks the dependent conclusion; optional worker loss permits labeled partial results. No spawning outside the plan, recursive self-invocation, autonomous new projects or unauthorized publication.
