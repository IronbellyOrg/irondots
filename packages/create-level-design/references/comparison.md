## Fair comparison protocol
Freeze same research/template/source bundle, two identical level briefs, accepted mechanics and art inputs for both systems. Generate two documents per pipeline from fresh sessions with the same allowed input content. Record actual prompts/tool calls, missing capabilities, time/cost only where observable, source versions and output hashes. Compare A1 versus B1 and A2 versus B2; do not compare four different concepts as if platform performance were isolated. Blind system identity for substantive review where feasible. Score 0 missing/contradictory, 1 partial, 2 adequate, 3 strong on source fidelity, player experience, spatial clarity, engineering handoff, art/narrative coherence, dependencies, testability, editability and consistency. Critical failures (invented accepted mechanics, hidden missing inputs, unsafe disclosure, fake links or claimed unrun tests) fail regardless of aggregate score. Reviewer proposes five improvements per document, debates and implements justified refinements; retain both raw and improved variants so post-edit quality is not mistaken for first-pass performance. Conclude strengths/weaknesses and conditional recommendation, not universal platform winner from n=2.
